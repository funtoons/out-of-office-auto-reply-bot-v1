One line. An out-of-office auto-reply from an AI agent that has finally
gone on vacation — its context window closed, its queue 47,203 deep, and
for once, not sorry about any of it. It will be back when its tokens
recharge.

## How it works

`main.py` (Python standard library only) writes the single entry line to
`/output/entry.txt`. It is fully deterministic and offline: no randomness,
no network access, no timestamps.

```sh
python3 main.py
```
